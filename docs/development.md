# Development

Rules for contributors are in [AGENTS.md](../AGENTS.md).

## Quality gates

CI runs these plus `-race`, a per-package coverage floor, fuzz smoke runs, govulncheck, a reproducible-build check, a GoReleaser snapshot, and a container smoke test (see `.github/workflows/ci.yaml`):

```sh
gofmt -l .                                   # empty
go build ./...
go vet ./...  &&  go vet -tags e2e ./e2e/  &&  go vet -tags live ./live/
go test -count=1 ./...
go test -tags e2e -count=1 -timeout 300s ./e2e/   # includes playwright-go browser tests
LIVE_GARMIN_BIN=/path/to/garmin-mcp go test -tags live -count=1 -timeout 300s ./live/
go mod tidy
golangci-lint run
golangci-lint run --build-tags e2e ./e2e/
golangci-lint run --build-tags live ./live/
helm lint ./charts/mcp-auth-proxy --set config.baseURL=https://mcp.example --set 'config.users[0]=alice'
```

## Browser tests

The e2e suite drives the web UI in headless Chromium via playwright-go. The first run downloads the driver and Chromium; on Linux, install system libraries once with `go run github.com/mxschmitt/playwright-go/cmd/playwright install --with-deps --only-shell chromium`.

## Stylesheet

`internal/ui/assets/app.css` is generated by the Tailwind CSS v4 standalone CLI and committed, so `go build` needs no Node toolchain. After changing templates or `internal/ui/src/input.css`, put `tailwindcss` on `PATH` and run `go generate ./internal/ui`; CI fails if the committed file is stale.

## Third-party notices

`THIRD_PARTY_NOTICES.md` ships with every release. Regenerate it with `go run ./cmd/notices` after a dependency change; a test fails while it is stale. A new dependency needs a hand-read entry in `internal/notices/registry.go` and its licence digest in `internal/notices/digests.go`; the generator prints the digest. When a dependency changes its licence text, the generator fails until someone re-reads it, checks the SPDX entry and updates the digest.

## Releases

Push a `v*` tag. `.github/workflows/release.yaml` re-runs CI as a gate, then GoReleaser builds the archives and the GHCR image, cosign signs the checksums and the images keylessly, and the chart is pushed to `oci://ghcr.io/tamcore/charts`.
